## 🚀 Usage

### Browse Online

You can read any book directly on GitHub by navigating to the [`books/`](books/) directory and clicking on an HTML file. See [`INDEX.md`](INDEX.md) for a navigable index.

### Clone for Offline Reading

```bash
git clone https://github.com/farmrecipes67/gutenberg-top10-classics-html.git
cd gutenberg-top10-classics-html
```

Then open any `.html` file in the `books/` directory with your preferred web browser:

```bash
# Example: open Frankenstein in your default browser
open books/frankenstein.html        # macOS
xdg-open books/frankenstein.html    # Linux
start books/frankenstein.html       # Windows
```

No build tools, dependencies, or server required — each file is a self-contained HTML document.
